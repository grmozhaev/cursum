# Cursum v2 preview

V2 keeps a separate copy from the original Cursum app. Sign in with the same Cursum account and choose whether to upload the browser copy or use the v2 cloud copy. Browser changes are synchronized after setup, and conflicts require an explicit choice. Download backups before replacing data.

The Supabase schema for the v2 copy is documented in `supabase-v2.sql`. Public sign-ups should stay disabled. Never put a secret or service-role key in this public repository.
